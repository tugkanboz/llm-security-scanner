# Code of conduct

This project adopts the **Contributor Covenant v2.1** as its code of
conduct. The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## TL;DR

- Be respectful and welcoming. Assume good faith.
- Focus on what is best for the community and the project.
- Disagreement is fine; personal attacks are not.
- Remember that this is a security-research project: keep discussion
  technical and constructive.

## Scope

This applies to all project spaces — issues, pull requests, discussions,
review comments, and any official chat or communication channel — and
also when an individual is officially representing the project in public.

## Reporting

If you observe behaviour that violates the covenant, please contact the
maintainer privately at:

> tgkn.boz@gmail.com

Reports will be reviewed and investigated promptly and fairly. The
maintainer is obligated to respect the privacy and security of the
reporter.

## Enforcement

The maintainer may take any action they deem appropriate, including
warning the contributor, removing comments, or revoking project
participation, in line with the enforcement guidelines section of the
Contributor Covenant.
